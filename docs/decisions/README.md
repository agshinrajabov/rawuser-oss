# Decision records

Each file here is the reason for one decision, written when it was made.
This is a first set, chosen for what Rawuser most wants to be read for:
how it tells where a visit came from, and where it draws its privacy
lines. More follow with later releases.

| Record | What it decides |
|---|---|
| [0005](0005-edge-side-v1-classification.md) | A visit is classified at the edge, from a verified list of user agents |
| [0006](0006-intent-vector-foundation.md) | The reason for a visit is a vector, not one label |
| [0023](0023-entry-path-intent-signal.md) | The page a visitor opens is itself a signal |
| [0028](0028-in-app-source-recovery.md) | In-app browsers and click id names recover a lost source |
| [0029](0029-source-recovery-layers.md) | "Some app" and "some tracked link" when the app is unknown |
| [0030](0030-source-vocabulary-learning.md) | One vocabulary of sources, and how unknown ones are learned in aggregate |
| [0033](0033-compliance-first-privacy.md) | The bar is the law and the audit, with hard lines that never move |
| [0036](0036-country-on-events.md) | The visitor's country is stored with each event |
| [0037](0037-event-data-kept.md) | Event data is kept for the life of the account |
| [0038](0038-direct-visitors.md) | What a visit with no signal can still be offered |
| [0039](0039-remembered-choice.md) | A returning visitor is remembered by its own browser |
| [0040](0040-open-source.md) | Rawuser is open source |

Read them as a history. Later records amend earlier ones, and some record
a lighter line than a privacy review asked for; 0036 and 0038 say so
outright. The rules that hold today are in
[../privacy-rules.md](../privacy-rules.md).

The records were written inside the project, so some point to records,
specs and a backlog that are not published. Customer names are taken out.
0039 and 0040 are shorter public versions of longer internal records; the
others are as they were written.
